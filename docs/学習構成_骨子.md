財務の道は下の骨子のとおり F1〜F5（考え方）＋ F6（3店舗の財務：店舗別損益・資金繰り・出店の投資判断・役員報酬と社保・融資と決算の着地・社長への伝え方）＋卒業試験（90%で「財務支援 独り立ち」）を次に作る。

## Why

- スタッフに「日々の仕訳を正しくやる力（経理）」と「その数字で会社をどう動かすかの考え方（財務）」の両方を、現場の場面から少しずつ身につけてもらう
- 財務は、カルロさんの考え方（視点27・知識58・思考の実演9・盗める型13）を、初心者が1個ずつ刷り込める形にする。いまの「財務の部屋」は読む資料室で、学ぶ順番と確認の仕組みがない

## 全体像

```
入口（名前＋合言葉）
 ├─ 経理の道 … 実力診断20問 → 8章28ステージ104問（公開済み）

      └─ 財務の部屋（資料室：視点・知識カード・思考の実演・盗める型。ローカルにあり、未公開）
```

## 財務の道（新規）の章立て

カルロさんの「思考回路 5つの段」を章にして、27の視点を配る。1ステージ＝1視点。

| 章 | 段 | ステージ（視点） | 身につく一言 |
|---|---|---|---|
| F1 未来から逆算 | 来期の決算書を先に描く | ①未来の決算書から逆算 ②厳しめに引いて上振れを待つ ③売上を塊に分けて読む ④時期と時間差を武器にする | 今期の数字は来期の融資のための材料 |
| F2 値札を付ける | 差を1つの金額に | ①迷ったら1つの金額に換算 ②確率×金額で期待値 ③税率の差で置き場所を決める ④お金の出ない節税から | 「〇〇する代金＝△円」で比べる |
| F3 貸す側の目 | どう見られるか | ①貸す側の目で見る ②情報の通り道を読む ③実データと突き合わせる ④固定と変動に分けて率で引く ⑤機械的なルールで迷いを消す | 役員貸付金は悪、借入金は良。通帳で検算してから未来を語る |
| F4 期限で押す | 今決める理由 | ①期限＝最後のチャンス ②ルールと契約を先に決める ③財布を目的別に分ける ④社長の時間は売上に回す | 期限カレンダーを先に出す |
| F5 本人が選ぶ | 価値観で決める | ①最後は本人の価値観で選ばせる ②相手の席から見る ③お金よりストレスで測る ④信頼関係も資産 ⑤数字を本人に持たせる ⑥考えながら話し、間違えたら直す | 正解を押しつけず、軸を見せて選んでもらう |
| ボス戦 思考の実演 | 9つの実例 | 「社長への貸付金をどう消す？」「役員報酬をいくらに？」「1期目は赤でいい？」など9ケース。考える順番を並べ替える問題 | カルロさんの手順を自分で再現できる |

- 残り4視点（AIで細かく割る／リターンで集中先を絞る／作業を売らずやり方を売る／契約の瞬間に上位を置く）は F5 の発展ステージか、資料室の「盗める型」で扱う
- 知識カード58枚は、各ステージの解説の下に「参考カード」として紐づける（融資14・役員18・税務26・予測10・資金繰り9 など）
- 問題の数：診断10＋23ステージ×3＝約80問。絵は視点27枚＋問題用

## 「今日の考え方」（刷り込みの仕組み）

- 入口を開くたびに、視点を1枚だけ見せる（27視点を順に。見た数が記録される）
- 1枚＝「視点の名前・一言・カルロさんの発言の言い換え1つ・今日の自分への問い」。30秒で読める
- 27日で一周。二周目からは「むずかしかった」の印が付いた視点を優先

## 学ぶ順番（おすすめ）

1. 経理の道の実力診断 → 低い章から
2. 並行して「今日の考え方」を毎日1枚
3. 経理の第8章（BS/PLの読み方）を終えたら財務診断 → 財務の章へ
4. 財務の部屋は、気になった視点を深掘りする資料室として使う
